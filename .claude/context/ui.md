# 市场异动追踪 — 短线投资者版页面原型

> 目标用户：A股短线投资者（追涨停、做连板、看情绪周期）  
> 核心使用时段：开盘前（9:00~9:30）+ 盘中（9:30~15:00）+ 收盘复盘（15:30~22:00）  
> 核心决策链：**今日情绪强弱 → 哪个板块在轮动 → 龙头是谁 → 明天还能打吗 → 市场在说什么**

---

## 一、整体布局

```
┌──────────────────────────────────────────────────────────────────────┐
│  顶部导航栏                                                            │
├───────────────────────────────────────────┬──────────────────────────┤
│                                           │                          │
│  主内容区（左）                             │  AI 对话区（右，常驻）    │
│  ① 情绪仪表盘 + 7x24新闻播报（首屏）        │                          │
│  ② 七大功能 Tab                            │  上下文感知：             │
│     涨停数据 / 晋级分析 / 板块异动           │  用户看哪个Tab            │
│     时间线 / 情绪筹码 / 市场情报 / AI观点    │  AI就知道在分析什么        │
│                                           │                          │
└───────────────────────────────────────────┴──────────────────────────┘
```

**布局比例**：主内容区 `65%` / AI 侧边栏 `35%`（宽一些，短线投资者问题多）  
**主题**：深色（`#0d0d1a`），全页统一，消除断层感

> 短线的核心判断：**今天情绪几成？还能持续几天？**  
> 不可折叠，始终置顶。左侧为情绪仪表盘，右侧为 7x24 新闻滚动播报，两栏并排。

**对短线投资者的意义说明**（每个指标都需要有解读标注）

|指标|短线含义|显示方式|
|---|---|---|
|情绪温度|综合打分，决定是否出手的第一依据|大数字 + 颜色渐变（冷蓝→热红）|
|涨停家数|今天市场活跃度，越多越容易赚钱|红色大字 + 昨日对比|
|炸板率|低炸板率=市场惜售=情绪好；高=风险大|百分比 + 好/中/差 标注|
|连板晋级率|打板策略核心胜率参考|百分比 + 历史均值对比|
|涨跌比|普涨普跌判断，决定仓位|比值 + 上涨/下跌家数|
|主力净流入|机构今天在做多还是撤退|金额 + 流入方向板块|

**7x24 新闻设计规格**

|元素|规格说明|

**排序逻辑**：按短线投资者决策流程排列

1. 今天谁最强，涨停龙头在哪、补涨机会在哪（①，内含涨停股/强势股池双子视图）
2. 再判断龙头明天能不能继续（②）
3. 看哪个板块在轮动（③）
4. 复盘全天节奏（④）
5. 看情绪和筹码是否支撑（⑤）
6. 看市场舆论和论坛在讨论什么（⑥）
7. 问 AI 综合判断（⑦，也可用右侧常驻栏）

**强势股字段含义**（与涨停股的差异对比）

|字段|涨停股对应字段|强势股含义|
|---|---|---|
|强度评分|连板数|量化今日综合强弱，替代连板数的排序作用|
|量比|—|>2 说明今日主力参与，放量明显；<1 缩量需谨慎|
|特征标签|—|形态快速判断，见下方标签体系|
|板块 🔥|板块|🔥 = 今日主线板块，主线内补涨胜率显著高于非主线|

**特征标签体系**（后端打标，前端直接渲染，无需前端计算）

```
连续上涨类：连续2日↑  连续3日↑  连续5日↑
形态突破类：突破前高   突破年线   突破平台
量价关系类：温和放量   主力流入   缩量回踩✓  放量滞涨⚠
板块关联类：主线板块🔥  次线板块   独立行情
```

**为什么「主线板块🔥」标签最重要**

今日云计算是主线，强势股里属于云计算板块的股票，跟随龙头补涨的胜率远高于其他板块强势股。用户第一眼应该能筛出「主线板块内的强势股」这个交集，这是补涨机会的最优解。默认开启「主线板块优先」排序。
