# OpenATrading 产品功能设计文档

## 产品定位

**OpenATrading** 是一个 AI-native A 股短线交易决策工作台。

核心目标：**帮助短线交易者理解市场**，而非展示数据。

系统回答交易者每天的核心问题：
- 今天谁最强？
- 主线是什么？
- 龙头是谁？
- 情绪如何？
- 风险在哪里？
- 明天可能如何演化？

---

## 产品核心模块

### 1. 市场状态面板（Market Overview）

实时市场全景驾驶舱，一眼看清全市场状态。

**核心指标（KPI Cards）：**
- **情绪温度（0-100）**：综合情绪温度、炸板率、涨跌比计算，展示偏热/正常/偏冷
- **涨停家数**：当日涨停股票数量，附跌停家数对比
- **炸板率**：涨停后打开的比例，偏高/正常/偏低标注
- **昨日涨停表现**：昨日涨停股今日平均收益，反映赚钱/亏钱效应
- **涨跌比**：上涨 vs 下跌家数比例，红绿双色标识

**三大指数行情卡：**
- 上证指数（000001.SS）
- 深证成指（399001.SZ）
- 创业板指（399006.SZ）
- 实时价格、涨跌幅、成交额

**风险定级与决策摘要：**
- 根据涨跌比和炸板率自动判定风险等级（高/中/低）
- 生成可操作的决策摘要文字

数据来源：选股宝（XuanGuBao）flash-api

---

### 2. 涨停结构分析（Limit-Up Analysis）

**强势股列表：**
- 当日涨停股票完整列表
- 字段：代码、名称、涨跌幅、连板天数、炸板次数、换手率、市值、涨停原因
- 支持排序和筛选

**涨停板晋级分析（Promotion Ladder）：**
- 自动对比今日涨停与昨日涨停
- 分级展示晋级结果：
  - 晋级成功（连板股，按昨日板数分组）
  - 断板（涨停失败）
  - 首板（新晋涨停）
- 每级晋级率可视化（进度条 + 百分比）
- 断板率统计
- ST 股票过滤开关
- 展开查看各级明细

数据来源：选股宝 limit_up / yesterday_limit_up 池

---

### 3. 板块异动（Sector/Plate Abnormal Movements）

追踪行业板块与概念板块的异常价格变动。

- 按板块/概念聚合展示异动
- 每个板块显示：名称、涉及股票数量、异动原因
- 展开查看板块内个股明细（代码、名称）
- 点击股票名称弹出 K 线分析面板

数据来源：韭研公社（JiuYanGongShe）field/action API

---

### 4. 时间线（Timeline & Market Events）

**双视图设计：**

**A. 今日大盘异动：**
- 当日盘中异动事件列表
- 事件类型标注（上涨↑/下跌↓ emoji）
- 标题、板块标签、时间戳
- 可点击查看详情

**B. 本月事件时间轴：**
- 按日聚合的市场事件
- 事件重要级别评分（星级标注）
- 话题标签、内容摘要
- 事件数量统计

数据来源：选股宝 dapan-abnormal API + 韭研公社 timeline API

---

### 5. 情绪筹码分析（Sentiment & Chip Analysis）

专用情绪周期分析视图，评估市场情绪阶段，提供历史对比和风险评估。

**情绪周期判定：**
- 当日情绪评分（0-100）
- 近 10 个交易日情绪趋势
- 市场阶段判定：偏热 / 正常 / 偏冷
- 连续过热/过冷天数追踪

**筹码结构指标：**
- 涨停家数、跌停家数
- 炸板率
- 涨跌比

**智能预警：**
- 连续 3 日过热 → 历史规律提示次日降温概率高
- 连续 3 日过冷 → 历史规律提示可能出现修复
- 情绪 + 炸板率交叉风险评估

**历史情绪表格：**
- 近 10 日情绪值、涨停数、炸板率、涨跌比、市场特征

数据来源：选股宝 market overview（当前 + 历史）

---

### 6. 市场情报（Market Intelligence）

聚合韭研公社和淘股吧的社区情绪，识别热门标的和话题。

**双视图：**

**A. 题材热度与舆情：**
- **热门股票排行**：按社区文章提及频次排名（附提及次数徽标）
- **热门文章**：韭研公社热门文章（点赞、评论、转发、热度分）
- **淘股吧推荐**：淘股吧推荐文章（浏览量、回复数）
- 可展开查看文章内容，支持跳转原文
- 整体舆情趋势标签：偏多 / 中性 / 偏弱

**B. 论坛热帖聚合：**
- 淘股吧用户内容聚合（需配置 TAOGUBA_USER）

数据来源：韭研公社社区文章 + 淘股吧推荐 API

### 7. 实时资讯（News Feed）

实时财经新闻推送，来自财联社（CLS）电报服务。

- 财联社电报数据流
- 新闻重要级别标注（A 级/红色：最重要；B 级：重要；普通）
- 来源筛选（全部 / 财联社 / 韭研公社）
- 时间显示（HH:MM 格式）
- 支持侧边栏和全 Tab 页两种展示模式

数据来源：财联社 CLS 电报 API

---

### 8. K 线分析面板（K-line Drawer）

任意股票的滑入式技术分析面板。

- **四个周期切换**：分时、日K、周K、月K
- K 线图渲染（新浪财经 GIF 图片源）
- **实时报价**：当前价、涨跌幅、成交额
- **12 项详细指标**：开盘价、昨收、最高、最低、振幅、换手率、PE（市盈率）、PB（市净率）、总市值、流通市值、量比、成交量
- **板块归属**：该股票所属的所有板块/概念，含平均涨幅和异动原因
- 可展开板块详情弹窗
- ESC 键关闭

数据来源：选股宝 realtime API + plates_by_any_stock API + 新浪财经图表

---

### 9. 迷你分时图预览（Mini Chart Preview）

全界面统一的股票悬浮图表预览。

- 鼠标悬停股票名称 → 弹出分时图 GIF
- 智能定位：自动调整避开视口边界
- 点击放大 → 可缩放浮层（滚轮缩放 0.5x - 8x）
- 200ms 延迟加载，避免快速移动时的闪烁

数据来源：新浪财经分时图 GIF（`image.sinajs.cn`）

---

### 10. 行情回放（Market Replay）

完整 K 线回放系统，以实时或加速方式回放行情数据。

- **K 线图**：基于 lightweight-charts 的蜡烛图 + 成交量柱状图
- **播放控制**：播放/暂停、重置、速度控制（1x / 2x / 4x / 8x）
- **进度条**：可拖拽到任意时点
- **股票代码输入**：任意 A 股代码加载分钟级数据
- 颜色规则：红涨绿跌（A 股惯例）

## AI 系统

### 11. AI 副驾驶（AI Copilot）

AI 不是聊天机器人。AI 是「交易副驾驶」。

**两个使用入口：**
- **侧边栏模式**（交易终端内）：340px 右侧固定面板
- **全屏模式**（/copilot 路由）：独立全页对话界面

**核心能力：**

- **角色驱动对话**：选择不同 AI 角色（如 zarili 量价派、游资操盘手、量化分析师、风控官），每个角色有独立的投资哲学和交易策略
- **实时市场上下文**：自动向 AI 注入当前行情数据（大盘概况、板块异动、强势股），AI 基于真实数据进行分析
- **多轮对话**：保持会话历史，可持续追问
- **流式响应**：Token 级实时打字输出
- **Markdown 渲染**：支持富文本、表格、代码块
- **建议问题**：空状态时提供快速启动问题

**AI 行为原则：**
- 主动解释市场现象
- 主动识别和提醒风险
- 主动总结市场状态
- 禁止给出明确买卖建议
- 禁止保证收益、预测具体涨跌点位

LLM 配置：默认 DeepSeek，支持任意 OpenAI 兼容 API

### 12. AI 角色策略系统（Multi-Role Strategy System）

多智能体架构，不同「角色」以不同的投资哲学独立分析市场、做出交易决策。

**内置角色：**

| 角色 | 风格 | 核心理念 |
|------|------|---------|
| **zarili 量价派** | 量价低吸 | 一切围绕量价关系，含择时系统（指数方向、量能级别）、选股（成交量前排、均线粘合+量能突破）、执行（低吸、板块分歧买入）、风控（行情难做时空仓）。策略提炼自淘股吧用户"zarili"30+ 篇实盘复盘文章 |
| **游资操盘手** | 短线打板 | 15 年打板经验，关注涨停情绪、空间板高度、资金流向 |
| **量化分析师** | 数据驱动 | 关注涨跌比、成交分布、板块集中度、情绪指标 |
| **风控官** | 保守风控 | 监控炸板率、跌停家数、尾盘异动，劝阻追高 |

**角色管理：**
- 创建自定义角色（自定义名称和策略描述）
- 编辑策略文本（支持 Markdown）
- 删除角色（连带清除所有持仓和交易记录）
- 重置账户（清空持仓和历史，保留策略）

**策略合并模式：**
- `base_only`：仅使用系统内置策略
- `supplement`：内置策略 + 用户补充（默认）
- `override`：用户完全自定义

### 13. 自动化交易决策（Automated Trading）

定时任务驱动的全自动市场数据采集、AI 分析和交易执行。

**定时任务：**

| 任务 | 频率 | 说明 |
|------|------|------|
| 数据采集 | 交易时间每 30 分钟 | 采集大盘概况、涨停数据，存入 SQLite |
| AI 决策 | 每个交易日 00:00 | 全量 AI 分析，生成交易指令 |
| 持仓监控 | 交易时间每 1 分钟 | 检查止盈止损条件单 |
| 新闻推送 | 交易时间每 5 分钟 / 非交易时间每 30 分钟 | 推送重要新闻 |

**决策流程：**
1. 获取当前大盘数据
2. 获取历史上下文（近 5 日）
3. 更新所有持仓价格
4. 对每个角色：
   - 构建市场上下文 + 持仓上下文 + 历史数据
   - 执行 AI agent 循环（多轮工具调用）
   - 解析结构化 JSON 输出（分析 + 交易指令）
   - 执行交易：买入（含验证：最小股数、100 股整数倍、单票 30% 上限、总仓位 90% 上限）、卖出（清仓该标的）、持有（不操作）
   - 记录交易日志
   - 发送通知

**AI 可用工具（Function Calling）：**
- `get_limit_up` — 获取涨停列表
- `get_limit_down` — 获取跌停列表
- `get_market_overview` — 获取大盘概况

---

### 14. 持仓与盈亏管理（Portfolio & PnL）

每个 AI 角色维护独立的模拟持仓和完整交易历史。

- **模拟资金**：每角色初始 100 万人民币
- **当前持仓**：标的、成本价、现价、股数、入场理由、入场日期
- **交易日志**：全部买卖记录（标的、价格、股数、理由、时间）
- **已平仓历史**：历史完成交易，含买入/卖出价、盈亏比例、持仓时长
- **盈亏曲线**：每日盯市净值曲线
- **盈亏可视化**：Sparkline 曲线图（7 天 / 30 天 / 全部）
- **账户重置**：清空持仓和交易记录
- **角色删除**：完全移除角色及关联数据

数据存储：SQLite（`.atrading/data.db`）

## 交互与通知

### 15. Telegram Bot

完整交互式 Telegram 机器人，支持移动端查询、分析和接收通知。

**指令：**
- `/ask role_name question` — 向指定角色提问（开启多轮对话）
- `/new` — 清除对话历史，重新开始
- `/decision [role_name ...]` — 手动触发 AI 决策
- `/start` 或 `/help` — 帮助信息

**自动推送通知：**
- 数据采集摘要（每 30 分钟）
- AI 决策结果（每日）
- 交易通知（开仓/平仓）
- 重要新闻推送（A/B 级）

### 16. 多渠道通知系统

同步推送到多个平台：**Telegram、Discord、Slack、飞书/Lark**

- 可配置通知类型：数据采集、AI 决策、交易执行、重要新闻
- 每渠道独立开关控制

## CLI 与部署

### 17. CLI 命令行工具

完整命令行接口，支持数据查询、报告生成、AI 分析。

**典型用法：**
```
openatrading                           # 全量数据采集，Markdown 输出
openatrading --json                    # JSON 格式输出
openatrading --html                    # HTML 报告
openatrading --data limit_up,overview  # 选择性数据源
openatrading --ai                      # 数据采集 + AI 分析
openatrading --role zarili --ai        # 指定角色分析
openatrading decision                  # 手动触发每日决策
openatrading trade add|list|close      # 持仓管理
openatrading gateway start|stop|status # 网关服务管理
openatrading update --check            # 自更新
openatrading doctor                    # 系统诊断
openatrading init                      # 初始化配置
openatrading --list-roles              # 列出所有角色
```

可选数据源：overview, limit_up, limit_down, super_stock, field_item, plate_abnormal, timeline, sentiment, cls_telegraph, dapan_abnormal, market_trend, community

### 18. MCP Server

将系统能力暴露为标准化 MCP（Model Context Protocol）工具，供 AI Agent 调用。

**12 个 MCP 工具：**
- 市场数据查询：limit_up, limit_down, overview, super_stock, plate_abnormal
- 社区数据：field_item, timeline, community
- 新闻：cls_telegraph
- 情绪分析：sentiment
- 全量报告：run（支持 AI 分析）

## 客户端

### 19. Web 应用

- SPA 单页应用，React + TypeScript + Tailwind CSS
- 部署于 Vercel / Cloudflare Pages
- 暗色终端风格主题

### 20. 桌面客户端（Tauri）

- 原生桌面应用（macOS Intel + Apple Silicon、Linux deb/AppImage、Windows msi/exe）
- 无需浏览器即可使用
- API 调用通过 Tauri IPC 直连后端，无 HTTP 开销
- 窗口尺寸 1400×900
- 自动更新支持
