📦 下载安装

🖥️ 桌面端

支持 macOS / Windows / Linux 三大平台，原生桌面体验，内置行情数据引擎。从官网下载对应安装包。

🍎 macOS .dmg 🪟 Windows .exe 🐧 Linux .AppImage

或访问 openatrading.com/download

⌨️ CLI 命令行

适用于 Linux/macOS 环境，支持嵌入量化策略 pipeline、定时任务及 CI/CD 流程。

# 下载 CLI 二进制 curl -fsSL https://openatrading.com/cli/install.sh | bash # 或手动下载指定平台版本 # https://openatrading.com/cli # 验证安装 oa --version # 启动 Telegram Bot oa bot start --token YOUR_TELEGRAM_TOKEN

完整 CLI 文档：openatrading.com/docs/cli
