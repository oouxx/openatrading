# ADR-0001: AI 的角色是复盘向导，不是分析师

**状态：** 已接受
**日期：** 2026-06-19
**关联：** docs/ai-native-desktop-plan.md §1.3, §3 Phase 2.3, Phase 3

## 背景

原计划里 AI 的角色是摇摆的：Phase 1 像查询层（问财式取数分发），Phase 2.3「多 Agent 并发分析」和 Phase 3「收盘自动跑全市场分析推送结论」又像分析师（AI 替用户下结论）。用户在 grilling 中明确两点：

1. 产品定位是**短线复盘 + 辅助决策，非自动化交易**，目标是**减少复盘时间**。
2. 复盘慢的真正瓶颈是**"不知道看哪些数据、怎么从数据得出结论"**——是认知路径问题，不是取数问题。同时用户**不希望"全部交给 AI"**，要自己判断。

这构成一个表面张力：用户想要结论，但又拒绝 AI 直接给结论。

## 决策

**AI 的角色是"复盘向导"（guide / coach），不是"分析师"（analyst）。**

- AI 不输出"主线是 AI、龙头是 XX"这类**结论**。
- AI 输出**得出结论的路径**：该看哪些数据、按什么顺序看、每一步说明什么。例如"先看今日晋级率→若断板率高则看炸板集中在哪个题材→据此判断主线强弱"。
- 最终判断（龙头是谁、主线是什么）由**用户**做出，AI 只铺路径、取数据、呈现。
- 数据呈现保持高密度（表格/图表），AI 不把数据稀释成自然语言结论。

## 影响与取舍

- **取舍：** 牺牲了"AI 直接给答案"的即时满足感，换取用户对结论的拥有感和可信度（AI 不替人拍板，降低幻觉风险）。
- **差异化锚点：** 问财解决"取数快"，本产品解决"路径不清"。AI 的价值不在取数，在**编排复盘的认知步骤**。
- **对 Phase 的影响：**
  - Phase 1（布局 + artifact 数据渲染）：✅ 符合，保留。AI 铺路径、右侧高密度数据用户自判。
  - Phase 2.3（多 Agent 并发分析）：⚠️ 重新定义。不是"多 Agent 各下结论"，而是"多 Agent 各负责一条复盘路径/一个维度（情绪/晋级/龙头候选），输出**数据 + 该看什么**，不下结论"。改名/改义。
  - Phase 3（收盘主动推送分析结论）：⚠️ 推送内容从"AI 的分析结论"改为"今日复盘路径就绪 + 数据快照"，等用户来取并自己走完路径。是否仍叫"推送"待 Phase 3 grilling 再定。
