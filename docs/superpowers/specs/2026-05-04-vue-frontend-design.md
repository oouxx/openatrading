# Vue 前端信息汇聚展示设计

**Date:** 2026-05-04
**Status:** Approved by user
**参照风格:** xuangutong.com.cn
**设计目标:** 信息的汇聚和清晰展示

---

## 1. 整体布局（参照 xuangutong 风格）

**Top Nav**：深色固定导航栏，左侧 Logo + 标题「A股市场异动追踪」，右侧「刷新数据」「导出报告」按钮。

**Hero Section**：4 个 KPI 卡片横向排列：
- 📈 涨停家数（大号数字 + 环比箭头）
- 📉 跌停家数（大号数字 + 环比箭头）
- ⚠️ 炸板率（百分比 + 红/绿色标记）
- 🎯 市场情绪（「高/中/低」+ 对应颜色圆点）

**Tab Bar**：5 个 Tab 按钮（涨停榜 / 板块异动 / 舆情分析 / AI 观点 / 淘股吧），当前选中态高亮。

**Content Area**：根据选中 Tab 动态渲染对应数据模块。

**Footer**：版本号 + 数据更新时间。

---

## 2. 各 Tab 内容设计

### Tab1：涨停榜 📈
- **连板梯队表格**：列 = 连板天数、股票代码、名称、涨跌幅、换手率
- **热门板块标签云**：板块名 + 出现次数，字体大小映射热度
- **风险提示**：炸板率 >30% 时显示红色警告条

### Tab2：板块异动 🗺️
- **异动事件列表**：时间、板块名、事件描述、相关股票
- **板块热度排行**：横向 Bar 图（用纯 CSS 实现，不引入图表库）

### Tab3：舆情分析 💬
- **热门股票 TOP10**：代码、名称、提及次数（进度条样式）
- **热门文章列表**：标题、作者、热度、摘要（折叠展开）
- **趋势标签**：「看涨」「看跌」「震荡」带颜色胶囊

### Tab4：AI 观点 🤖️
- **三个角色卡片**：角色名（游资操盘手/量化分析师/风控官）+ 150 字观点 + 生成耗时
- 卡片顶部用颜色区分角色（橙/蓝/灰）

### Tab5：淘股吧 📝
- **用户方法论列表**：用户 ID、帖子数、最新更新时间
- 点击可展开查看「短线情绪」「市场判断」等历史观点摘要

## 3. 数据流动

```
Tauri (or Web) 启动
    ↓
调用 API 层 (src/api/*)
    ↓
核心逻辑 (crates/core) 拉取数据
    ↓
Report 聚合 (MarketOverview + Stocks + Sentiment + AI)
    ↓
Vue 响应式状态更新 (Pinia store)
    ↓
各 Tab 组件消费对应数据片段
```

**关键点**：API 层已建好（`src/api/`），Tauri 模式调 `invoke`，Web 模式调 `wasm`。

---

## 4. 技术选型

| 项目 | 选型 | 理由 |
|------|------|------|
| 框架 | Vue 3 + TypeScript | 已搭建，组合式 API |
| 状态管理 | Pinia | Vue 3 官方推荐，轻量 |
| UI 组件 | 自建 + Tailwind CSS | 参考 xuangutong 简洁风格，避免重型库 |
| 表格 | 自建 `<table>` + CSS | 数据量小（<100 行），无需引入组件库 |
| 构建 | Vite | 已配置 |
